# AGENTS.md

Compact rulebook for this repository. Read it before any edit. It replaces the
Laravel Boost bootstrap text that used to live here; CLAUDE.md was a byte-identical
duplicate and has been deleted.

## What this repo is

Laravel 8 marketing site for Emplowise, rendered with Blade and also published as
static HTML to GitHub Pages. No Node build step; CSS bundles are generated by an
Artisan command. Every change must pass both the Laravel tests and the static
export.

## Commands

```bash
php artisan emplowise:bundle-css                 # regenerate site.css + hub.css
php artisan emplowise:seo-audit                  # 9 routes: title, description, keyword
php artisan emplowise:export-static build/static \
  --base=https://diocese-trees.github.io/Emplowise-Website-Phase-I \
  --audit-key=YOUR_KEY
php artisan test                                 # Feature + Unit suites
node tools/parity/check-ats.mjs
node tools/parity/check-interview.mjs
node tools/parity/check-profile.mjs
```

`check-chat-routing.mjs` needs a served export and headless Chromium:

```bash
php tools/parity/generate-chat.php
php artisan emplowise:export-static /tmp/chat-parity --base=http://127.0.0.1:8116
php -S 127.0.0.1:8116 -t /tmp/chat-parity &
chromium --headless=new --remote-debugging-port=9316 --no-sandbox --user-data-dir=/tmp/chat-parity-profile &
node tools/parity/check-chat-routing.mjs
```

## Locked contract

- **SEO copy freeze.** Do not rewrite headlines, body copy, meta titles, meta
  descriptions, FAQs, or bios in `config/emplowise.php` or
  `resources/views/pages/*.blade.php`. Allowed text changes: `Student Hub` to
  `EmploStart`, inline validation/loading/error strings, `aria-label` text, and
  the 404 page copy. Keep every existing URL route live.
- **Brand lock.** Keep the Emplowise navy/teal palette (`public/css/tokens.css`,
  `public/css/theme.css`), self-hosted Montserrat + Plus Jakarta Sans
  (`public/fonts/`, `public/css/fonts.css`), and official logos in `public/img/`.
  Contrast fixes may only tune lightness/opacity inside existing brand hues.
- **Dual deployment.** A change is done only when `php artisan test` and the static
  export both pass with no console or CSP errors.

## Global denylist

Never read these in full: `docs/screenshots/`, `composer.lock`,
`public/css/site.css` (generated), full `config/emplowise.php` (use targeted
reads or grep). `public/css/hub.css` is also generated.

## Mandatory loop

1. Read only the files in scope; grep the rest.
2. Edit.
3. Rebuild artifacts: `emplowise:bundle-css` after any CSS edit,
   `emplowise:export-static` after template/route/404 changes.
4. Run `php artisan test` and `emplowise:seo-audit`; add the parity scripts for
   toolkit or chat work.
5. Update the mapped docs (`CHANGELOG.md`, `README.md`, `docs/*.md`).
6. Commit with a `task-N: ...` message.
7. Check the rendered page at 1440x900 and 375x667 in light and dark mode.

Rollback: `git checkout -- . && git clean -fd`, then `git reset --hard HEAD~1`,
or reset to the `pre-redesign-backup` tag for a full reset.
